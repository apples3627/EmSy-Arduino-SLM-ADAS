# 네 Uno 협력 프로젝트 — 격리된 인터랙티브 HTML

`index.html`을 브라우저로 열면 동작합니다. 인터넷·설치·Arduino 연결이 필요 없습니다. 모든 HTML/CSS/JS/모델 파일을 이 폴더 안에 두며 다른 프로젝트 파일을 실행 중 읽거나 수정하지 않습니다. 폴더 전체를 복사해 팀원에게 전달할 수 있습니다.

## 체험 순서

1. 시작 후 HC-SR04 정상 거리 3회와 STOP ACK가 끝날 때까지 기다립니다. 기본0.25배속으로 가상 시간을 천천히 보여 줍니다.
2. 영어 입력 또는 예시 버튼으로 분류·통신·출력을 확인합니다. 네 보드 카드를 누르면 역할·레지스터·핀 설명을 볼 수 있습니다.
3. `go forward, lights on, wipers on, horn on`으로 다중 명령을 보냅니다. 모든 절 검증이 끝나야 출력이 적용됩니다.
4. 거리 슬라이더를20cm 이하로 움직이거나 센서 오류를 켭니다. ADAS가 이전 명령과 추론을 취소하며 모든 출력을 끕니다.
5. 거리를25cm 이상으로 복구합니다. 세 번 정상 확인 후에도 이전 동작은 다시 시작하지 않습니다. 새 명령을 보내야 합니다.
6. 전체 STOP 버튼, 충돌 명령, 안내 시나리오, 일시정지/70ms씩 진행으로 상태 변화와 로그를 살펴봅니다.

## 원본과 일치하는 부분

- 실제 프로젝트의 `95616d56` 학습 모델 E/W/O int8, B/C/scales float32를 `model.js`에 복사했습니다. `engine.js`는 float32 연산 순서로 V245/E16/H64/10출력 추론을 구현합니다. 키워드 대체 분류가 아닙니다.
- 최대192 ASCII 바이트/4절, 절마다96바이트/16단어, 연결어 문법, 입력 guard, confidence≥0.5, 중복 제거·충돌 거절·STOP 우선 처리를 재현합니다. 거절 또는 충돌 시 일부 출력도 실행하지 않습니다. STOP 이후 절은 추론하지 않습니다.
- ADAS20cm/25cm3회 hysteresis,70ms 샘플, 누락 echo30ms 후 fault, 안전 epoch, 추론 취소, OFF ACK 뒤 known, 변경 시 및500ms snapshot 공유,500ms 모터 lease,100ms 방향 반전 대기를 표현합니다.
- 실제 ADAS 정책에서 위험이 해제된 뒤21~24cm 측정은 물리 ALERT를 다시LOW로 만들지 않습니다. 그러나 MAIN은 clearCount≥3도 요구하므로 별도 STOP을 요청합니다. 화면은 물리 ALERT와 MAIN 차단을 구분합니다.
- 원본 경로·커밋·SHA256은 `SOURCE_SNAPSHOT.json`에 기록했습니다. 원본 펌웨어를 수정하지 않습니다.

## 설명용 추상화와 범위

이 페이지는 실제 AVR 펌웨어·보드·자동차를 실행하는 에뮬레이터가 아닙니다. UART/SPI/I2C 단계는 가상 이벤트로 표현합니다. 반복되는 정상 I2C 폴링은 로그에서 약500ms마다 요약하고 거리·안전 상태 변화는 바로 기록합니다. 분류절150ms, 출력 전송35ms/ACK70ms, snapshot 전달40ms는 관찰을 돕기 위한 **설명용 지연**이며 실물 성능 측정값이 아닙니다. 그래픽의 바퀴·와이퍼는 표시용 애니메이션입니다. 모델 softmax의 JavaScript exp와 AVR expf에는 작은 수치 차이가 있을 수 있습니다.

센서 샘플과 I2C 폴링을 하나의 표현 단계로 묶고 echo 폭 자체·레지스터 ISR·CRC/바이트 프레임·실물 전기 타이밍은 실행하지 않습니다. session EEPROM 저장, 로컬 버튼 latch, 링크 분리/재전송·watchdog, 추가 센서 SourceRegistry는 보드 설명에만 표시하며 자동 재현하지 않습니다. 상태 적용 확인은 논리 출력 ACK이며 실제 바퀴 회전이나 물리적 정지 거리 측정을 뜻하지 않습니다.

웹에는 WebSerial·USB·Bluetooth·WebSocket·외부 fetch·CDN·게시/업로드 기능이 없습니다. 주행·경적 조작은 화면 안에서만 동작하며 부저 소리를 실제로 재생하지 않습니다. 원본에서 모델을 다시 학습하거나 코드를 수정해도 이 snapshot은 자동으로 바뀌지 않습니다.
