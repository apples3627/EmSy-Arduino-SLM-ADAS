Twenty-eight known commands reject because of out-of-vocabulary words; one rejects for confidence; one in-vocabulary forward command is accepted as WIPER_ON. The 36 coincidental TRAIN phrase matches are disclosed: excluding them gives 74 semantic cases, accuracy 59.46%, macro F1 0.5883, known-command accuracy 25/55 (45.45%). None overlap VAL or TEST.

Four malformed cases all reject. Case/multiple-space/terminal-punctuation normalization passes. Tab and newline normalization variants reject, reflecting printable-ASCII/space-only contract, so these are not claimed as accepted. All raw scores, raw predictions, effective decisions, rejection reasons and OOV words are in `sealed_results_v1.jsonl`; invalid inputs have no neural scores.

Dataset SHA256 matches metadata. Recomputed counts: TRAIN 2220 (180/action, 600 UNKNOWN); VAL 666 (54/action, 180 UNKNOWN); TEST 888 (72/action, 240 UNKNOWN). Normalized cross-split duplicate count zero; template families are disjoint by split. Base action phrases are shared, so synthetic test scores measure family recombination, not free-form English generalization. Independent vectorized int8 inference agrees with scalar float32 within floating-point accumulation tolerances. Checkpoint and thresholds are selected from VAL in code; TEST features are first made after weight/threshold freeze. Loss decreases from 0.000724 at step 50 to 0.0000126 at step 1200; minimum validation loss checkpoint is step 1200. Learned float tensors and exported int8 tensors have consistent dimensions.

Actual host C++ compiled and evaluated 3901 cases with zero effective-decision mismatches against Python, maximum score discrepancy 7.61e-6. Separately compiled actual shard kernels on 770 inputs, combined with one main output bias, agree within 6.54e-6. Original full-model quantization scales are preserved. Byte limits 96/97, token limits 16/17, NUL/non-ASCII/internal punctuation and guards pass contract checks. STOP and UNKNOWN clear all software output flags, HORN_ON/OFF toggle horn, and nonfinite scores reject. Runtime kernel has no dynamic allocation. These software checks do not establish physical actuator behavior.

Independent float64 finite differences on 30 parameter entries (embedding, hidden weights/bias, output weights/bias, initial and trained values) pass; maximum absolute error 3.70e-11. The supplied V1 `metrics.json` gradient-check values disagree because its analytical variable was overwritten in the training loop while the numeric value remained from initialization. This is a reporting defect, not a backprop defect.

Uno build FAILS in V1: exported `SE` scale name conflicts with AVR's `SE` macro, independently reproduced after staging headers. Consequently V1 cannot claim Uno deployment readiness. Build log: `build_part0.log`. Tools: Python 3.14.0, NumPy 2.3.4, Apple clang via `/usr/bin/g++`, Arduino CLI 1.5.1, AVR core 1.8.6.

The model is a compact learned intent classifier, not an LLM. All V1 cases become post-audit regression checks after any revision informed by this report. A second holdout is sealed separately before revised model disclosure.
